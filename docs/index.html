Logo Overlay

Embed any PNG/JPEG logo at the center of the QR code. Pass logo_base64 in the encode request. EC is raised to H automatically.

⬣

Module Styles

Choose between square, dot, or rounded modules. All styles work with every output format.

🎨

SVG Gradients

Generate SVG QR codes with a linear gradient. Set foreground as start color and gradient_color as end color.

🏷

Badge Labels

Render text below the QR code using the embedded DejaVu Sans font — no external font dependencies required.

📦

Batch + ZIP Export

Encode up to 200 QR codes in one request with Tokio-parallel processing. Export all as a .zip archive.

📷

Camera Decode

Scan QR codes from device camera in the browser using WebRTC + jsQR. Works on desktop and mobile.

🌐

URL Decode

POST a URL and let the server fetch and decode it server-side via reqwest with a configurable size cap.

📊

Prometheus Metrics

GET /metrics exposes operation counters in Prometheus text format. Plug straight into Grafana.

⚡

WebSocket Live Stats

Connect to ws://host/ws/stats to receive JSON pushes on every operation with running totals.

🗄️

Persistent History

Every encode and decode stored in SQLite with thumbnails. Paginated REST history with per-item delete.

🛡️

Rate Limiting + Auth

Per-IP token-bucket rate limiting via governor. Optional X-API-Key header enforcement.

🌙

Dark / Light SPA

6-tab single-page dashboard. System-preference theming. Keyboard shortcuts. Persisted preferences.

Payload Builder

10 Structured Payload Types

Stop hand-crafting WiFi strings and vCard escaping. QRTools builds properly-formatted payloads via a typed JSON API.

📶
WiFiWPA / WEP / open, hidden
👤
vCard 3.0RFC 2426 contact card
💬
SMSsms: URI with body
✉️
Emailmailto: with cc/subject/body
📍
Geolocationgeo: lat/lon/alt
📞
Phonetel: URI
🔗
URLRaw URL passthrough
📝
TextAny plain text
📅
Calendar EventRFC 5545 VCALENDAR
₿
BitcoinBIP-21 bitcoin: URI

Use POST /api/payload/build to get the formatted string, or POST /api/payload/encode for immediate QR generation.

WiFi payload example:

// POST /api/payload/build
{ "type": "wifi", "ssid": "HomeNet", "password": "s3cr3t", "auth": "WPA", "hidden": false }
// Response: { "payload": "WIFI:T:WPA;S:HomeNet;P:s3cr3t;H:false;;" }
API Reference

14 REST Endpoints

All endpoints under /api/. Base URL: http://localhost:8080

MethodPathDescription
POST/api/encodeGenerate QR — PNG, JPEG, WebP, SVG with logo/badge/gradient options
POST/api/decode/jsonDecode base64-encoded image
POST/api/decode/uploadDecode multipart file upload
POST/api/decode/urlServer-side fetch URL & decode
POST/api/batch/encodeEncode up to 200 items concurrently, returns JSON array
POST/api/batch/exportSame body as batch, returns application/zip
POST/api/payload/buildBuild formatted payload string from typed JSON
POST/api/payload/encodeBuild payload + generate QR in one call
GET/api/historyPaginated history with thumbnails (?limit=&offset=)
GET/api/history/{id}Single history entry by UUID
DELETE/api/history/{id}Delete one history entry
GET/api/healthLiveness — { status, version, timestamp }
GET/api/health/readyReadiness — includes ops_total, history_entries
GET/metricsPrometheus text format counters
WS/ws/statsPush ServerStats JSON on every operation

Encode Request/Response

// POST /api/encode
{
  "data": "https://example.com",
  "format": "png",              // "png" | "jpeg" | "webp" | "svg"
  "ec_level": "M",             // "L" | "M" | "Q" | "H"
  "module_style": "dot",        // "square" | "dot" | "rounded"
  "logo_base64": "...",         // PNG/JPEG logo
  "gradient_color": "#2563eb",  // SVG only
  "badge_label": "Scan Me!"
}
// Response: { "id", "mime_type", "data" (base64), "width", "height", "thumbnail", "timestamp" }
Install

Up in under 60 seconds.

Three ways to run QRTools.

git clone https://github.com/vedLinuxian/qrtools-rust.git
cd qrtools-rust
docker compose up -d
# -> http://localhost:8080
# Requires: Rust 1.82+, libsqlite3-dev
git clone https://github.com/vedLinuxian/qrtools-rust.git
cd qrtools-rust
cargo run --release
# -> http://localhost:8080
curl -LO https://github.com/vedLinuxian/qrtools-rust/releases/latest/download/qrtools-linux-x86_64
chmod +x qrtools-linux-x86_64
./qrtools-linux-x86_64
Configuration

Env-based. No YAML required.

Drop a .env file in the root or pass variables to Docker.

HOST=0.0.0.0
PORT=8080
API_KEY=                   # blank = disabled
RATE_LIMIT_RPM=120         # per-IP; 0 = disabled
DB_PATH=qrtools.db
METRICS_ENABLED=true
MAX_UPLOAD_BYTES=10485760  # 10 MB
MAX_REMOTE_FETCH_BYTES=5242880
Architecture

Clean layered structure.

Services, API handlers, middleware, and static assets cleanly separated.

src/ ├── main.rs Axum server, routing, SQLite init, graceful shutdown ├── config.rs Env vars to Config struct ├── error.rs AppError -> HTTP response ├── state.rs AppState: pool, moka cache, broadcast channel ├── services/ │ ├── qr_engine.rs Core QR: formats, styles, logo, badge, SVG gradient │ └── payload_builder.rs 10 structured payload formatters ├── api/ │ ├── encode.rs POST /api/encode │ ├── decode.rs POST /api/decode/{json,upload,url} │ ├── batch.rs POST /api/batch/{encode,export} │ ├── payload.rs POST /api/payload/{build,encode} │ ├── history.rs GET/DELETE /api/history │ ├── health.rs GET /api/health{,/ready} │ ├── ws.rs WS /ws/stats via tokio broadcast │ └── metrics_handler.rs GET /metrics Prometheus exporter └── middleware/ ├── rate_limit.rs Per-IP token bucket (governor) └── auth.rs X-API-Key enforcement
